# 카드뉴스 레이아웃 디자인 방향성

> LinkedIn 카드뉴스(Phase 3)의 레이아웃·디자인이 **어떤 방향으로 정해지고 어떻게 바뀌어 왔는지**를 단계(phase)와 세부 과제(task)로 나눠 기록한다.
> 각 과제 문서에는 **세부 계획**(무엇을 왜 하려 했나)과 **결과**(실제로 무엇이 됐나, 실측값)가 함께 있다.
> 작성: 2026-09-15. 원본 기록(과제 실행 기록, 디자인 계획, 스크립트, 결정 로그)에서 디자인에 관한 내용만 모았다. 원본과 다르면 원본을 따른다.

## 방향성 한눈에

사용자가 준 캐러셀 템플릿(Figma 커뮤니티 무료 템플릿, 1080×1350 PNG 10장)의 **레이아웃·색·타이포 문법은 그대로 따르고, 사진 자리는 데이터 블록으로 바꾼다.** 카드의 목적은 정보 전달이므로 **항목을 생략하지 않고 장을 늘린다.** 렌더링 품질은 눈이 아니라 **브라우저 실측 검사로 강제**하고, 로컬과 CI가 **같은 글자 모양**으로 굽도록 맞춘다.

| # | 원칙 | 처음 정한 단계 |
|---|---|---|
| 1 | 템플릿의 틀(상단 바, 초대형 제목과 그라데이션 강조, 하단 알약)을 그대로 쓴다 | 1 |
| 2 | 사진·일러스트·타사 로고를 쓰지 않는다. 사진 자리에는 차트·배너·칩·흐름도 같은 데이터 블록을 넣는다(D12) | 1 |
| 3 | 카드에 개인 정보를 넣지 않는다. 좌측 상단은 프로젝트 이름만, 하단 알약에는 대시보드 주소(D10) | 1 |
| 4 | 항목을 생략하지 않는다. 한 장에 담기지 않으면 같은 종류의 장을 늘리고 쪽 표시를 붙인다(D15, 규칙 18) | 1 |
| 5 | 한 장에 강조(그라데이션)는 한 곳만 | 1 |
| 6 | 한글 조판을 우선한다: 단어 단위 줄바꿈(`keep-all`), 한 음절 줄 금지, 한글 라벨 자간 축소 | 2·3 |
| 7 | 넘침·겹침·줄 수는 굽기 전에 브라우저 실측으로 검사하고, 어긋나면 굽지 않는다 | 3 |
| 8 | 로컬과 CI가 같은 Noto 계열 글꼴로 굽는다. 글꼴이 없으면 두부 글자 카드를 만들지 않고 멈춘다 | 4·5 |
| 9 | 게시물 모습의 정본은 PNG다. PDF는 구운 PNG를 쪽마다 싣는다(D23) | 6 |
| 10 | 카드에 가설·시나리오 같은 내부 개념어를 싣지 않는다. 사전 정보가 없는 독자가 읽는다(D24) | 7 |

## 현재 규격 요약 (2026-09-15 기준)

**틀:** 1080×1350. 좌우·상단 여백 48px. 상단 바(22px/700, 좌측 `CONSUMPTION INSIGHTS` 밑줄, 우측 `소개`/`가격 변동 리포트`). 하단 알약(높이 56px, 아래 48px, 2px 그라데이션 테두리 `#FBD9B5→#F4645A`, 좌측 대시보드 주소, 우측 `넘기기 / →` 또는 `끝`). 본문 블록은 바와 알약 사이 세로 가운데 정렬, 최소 여백 24px.

| 토큰 | 값 |
|---|---|
| 배경 / 잉크 / 본문 회색 / 흐린 회색 | `#F6F5F3` / `#111111` / `#6E6E73` / `#A1A1A6` |
| 강조 그라데이션(제목 한 곳) | `#FBBF6B → #F9A14A → #F4645A` (위→아래) |
| 짙은 배너 | `#141414`, 글자 흰색 |
| 차트 미국 리전 / 서울 리전 | `#2F6BF6` / `#A9C4FD` |
| 흰 패널·타일 | `#FFFFFF`, 모서리 28px |
| 굵기 | 400과 700만 |
| 글꼴 목록 | `-apple-system, BlinkMacSystemFont, "Segoe UI", "Pretendard", "Noto Sans KR", "Malgun Gothic", "Apple SD Gothic Neo", "Noto Sans CJK KR", sans-serif` |

## 열린 과제

| 항목 | 상태 |
|---|---|
| 정기 카드가 머지 뒤 `site/cards/<날짜>/`로 게시되는 경로 | 3-9 종단 검증에서 실제 승인 스냅샷으로 확인한다 |
| 차트 장 리드의 시나리오 이름이 로컬에서 두 줄에 걸친다 | 실물 확인에서 지적 없음. 현재 조판 유지. CI에서는 한 줄이다 |
| 소개 3장(흐름)은 리드가 없어 제목과 단계 사이가 다른 장보다 좁다 | 실물 승인됨. 필요하면 여백만 조정한다 |
| 로컬에 Noto Sans KR이 없는 PC | 맑은 고딕으로 돌아가고, 넘치면 레이아웃 검사가 굽기를 멈춘다 |

**갱신 규칙:** 카드 디자인(틀, 토큰, 타이포, 장 종류, 조판 규칙, 레이아웃 검사)이 바뀌면 해당 단계에 과제 문서를 추가하거나 새 단계를 만들고, 이 파일의 단계 지도·현재 규격·결정 목록을 고친다.
