## 목표

사용자가 준 캐러셀 템플릿을 우리 데이터에 맞게 **어떻게 쓸지 방향을 정한다.** 코드를 쓰기 전에 쓸 틀과 뺄 요소, 장 구성, 항목이 많은 날의 처리 방식을 확정한다(규칙 13 디자인 게이트).

## 배경

- 대시보드(Phase 2-5a)와 같은 방식으로, 공개 산출물의 디자인은 사용자 템플릿을 바탕으로 만든다(규칙 13).
- 템플릿 10장 중 6장이 사진에 기대고 있다. 쓸 사진이 없고 타사 이미지·상표를 쓰지 않기로 이미 정했다.
- 카드는 LinkedIn에 사람이 올린다(D7 A안). 이미지로 퍼지므로 출처와 개인 정보 처리가 중요하다.

## 이 단계의 결과

- **틀:** 상단 바 + 초대형 제목(한 곳 그라데이션) + 본문 블록 + 하단 알약. 모든 장이 같은 틀을 공유한다.
- **대체:** 사진 6장 자리를 차트 카드, 짙은 순위 배너, 흐름도로 채운다.
- **장 구성:** 정기 카드는 표지 → 단가 변동 → 월 사용료 차트 → 월 사용료 변동 목록 → (순위 변동). 소개 카드는 4장(이후 Phase 3에서 마무리 안내 장이 붙어 각각 5장).
- **분할:** 단가 5줄, 월 사용료 6줄, 순위 배너 2개마다 한 장. 2장 이상이면 `(1/2)`.
