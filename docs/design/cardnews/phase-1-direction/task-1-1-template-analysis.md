## 세부 계획

**목표:** 템플릿의 레이아웃·색·타이포·컴포넌트 문법을 최대한 그대로 따르되, 우리에게 없는 요소(사진, 타사 로고, 작성자 이름)를 무엇으로 바꿀지 정한다.

**입력:** 사용자가 준 Figma 커뮤니티 무료 템플릿 "FREE Instagram & LinkedIn Carousel Template Design | The RLVNT Studios (Community)". PNG 10장, 1080×1350(4:5). 원본은 `_workspace/card-template/rlvnt-carousel/`에 역할이 드러나는 이름으로 두고 **저장소에 커밋하지 않는다**(출처와 취급 규칙은 그 폴더의 `SOURCE.md`).

**계획한 작업**
1. 장별 레이아웃을 분류하고 쓸 장을 고른다.
2. 색·여백·라운드 토큰과 타이포를 뽑는다(1080px 기준 근사값).
3. 템플릿 요소를 우리 데이터에 매핑한다.
4. 원본과 다르게 가는 곳과 이유를 적는다.

### 원본과 다르게 가는 곳

| 원본 | 우리 | 이유 |
|---|---|---|
| 사진이 지면을 채운다 | 데이터 블록 | 쓸 사진이 없고 타사 이미지를 쓰지 않는다 |
| 손글씨 스크립트체 | 쓰지 않는다 | 한글 시스템 글꼴에 대응하는 것이 없다 |
| 영문 초대형 제목 | 한글 기준으로 크기를 줄이고 행간을 넓힘 | 한글은 같은 크기에서 더 빽빽해 보인다 |
| 종이 질감(노이즈) | 넣지 않는다 | 이미지 없이 CSS로 재현하기 어렵고, 없어도 인상이 유지된다 |
| 외부 이미지·글꼴 | 하나도 두지 않는다 | 오프라인에서 그대로 굽고, 외부 요청이 없게 한다 |

## 계획과 달라진 점

- 없음. 토큰은 처음부터 "구현하며 원본과 대조해 맞춘다"는 근사값으로 두었고, 실제 조정은 과제 3-2에서 했다.

## 남긴 것

- 템플릿의 인상은 사진이 아니라 **배경색, 상단 바, 초대형 제목, 그라데이션 강조, 하단 알약**이 만든다는 판단. 이후 모든 장 종류가 이 틀을 공유한다.
