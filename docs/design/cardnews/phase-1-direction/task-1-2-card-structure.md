## 세부 계획

**목표:** 소개 카드와 정기 카드(가격 변동 리포트)의 장 구성을 정하고, 변동 항목이 한 장에 담기지 않을 때의 처리 방식을 정한다.

**처음 계획**
- 정기 카드: 표지 → 단가 변동 → 월 비용 영향(대표 조합) → 월 비용 변동(이어서) → 순위 변동 → 가정과 산출 근거. 장수는 고정하지 않는다(D11).
- 넘치는 항목은 **불릿 5줄로 자르고 `외 N건`으로 적는다**(D13).
- 소개 카드: 표지 → 문제 제기 → 구조(흐름도) → 현재 결과 → 가정과 산출 근거(5장).

## 결과

### 1. 생략안 폐기 → 장을 늘리는 규칙 (D15, 규칙 18)

사용자가 `외 {생략건수}건은 대시보드에 있습니다`가 정보 전달이라는 목적에 어긋난다고 지적했다. 생략 문구를 전면 폐기하고 규칙 18을 신설했다.

| 장 | 한 장에 담는 양 | 쪽 표시 |
|---|---|---|
| 단가 변동 내역 | 항목 5줄 | 2장 이상이면 제목 오른쪽에 `(1/2)` |
| 월 사용료 변동 내역 | 항목 6줄 | 같다 |
| 순위 변동 | 배너 2개 | 같다 |

- 카드에 실린 항목 수가 `events.json`의 항목 수와 다르면 생성을 멈춘다(누락 검사, 코드로 강제).
- 장수 상한은 두지 않는다. 10장을 넘으면 검토 PR에 경고만 남긴다.
- **실측 [확인]:** 단가 변동 7건을 넣어 구웠더니 단가 장이 `(1/2)`, `(2/2)` 두 장으로 늘고 7건이 모두 실렸다.

### 2. 고지 장 배제와 차트·목록 분리 (D16)

사용자 지시로 `가정과 산출 근거` 장을 뺐다. 장 하나를 고지에 쓰는 대신 변동 내역에 쓴다.
- 고지(`약정 할인을 제외한 모델 추정치`)는 차트 장 각주와 게시문 본문에 남긴다.
- 월 사용료를 **차트 장 1장 + 목록 장(6줄마다)** 으로 나눴다. "대표 장에 4줄까지" 예외가 사라져 장수 계산이 단순해졌다.
- 소개 카드는 4장이 됐다(과제 3-1에서 마무리 안내 장이 붙어 다시 5장).
- **실측 [확인]:** 전형적인 날이 4장(표지, 단가, 차트, 목록)으로 구워지고 마지막 장 하단에 `끝`이 나온다.

### 3. 용어와 장 역할 정리 (D17, 차트 장 제목)

- 카드 문안의 `월 비용`을 `월 사용료`로 바꿨다(D17). `월 사용료`는 4자라 104px 표지 첫 줄에 들어가고 강조 낱말이 둘째 줄로 떨어진다 [확인].
- 목록 장 제목을 `월 사용료 변동 내역`으로 바꿨다. 표지 `월 사용료 변동`과 글자가 겹쳤고, `단가 변동 내역`과 짝을 맞춘다.
- 차트 장 제목 `월 사용료 영향`이 무엇을 가리키는지 불분명하다는 지적을 받았다. 원인은 **제목(변화량)과 차트 내용(절대 금액)의 불일치**였다. `플랫폼별 월 사용료`로 바꿨다. 76px에서 한 줄에 들어간다 [확인].

| 장 | 역할 |
|---|---|
| 표지 | 무슨 일이 있었나 |
| 단가 변동 내역 | 벤더가 무엇을 바꿨나 |
| 플랫폼별 월 사용료 | 지금 어디가 얼마인가 |
| 월 사용료 변동 내역 | 얼마나 달라졌나 |
| 순위 변동 | 월 사용료가 낮은 순서가 어떻게 바뀌었나 |

## 계획과 달라진 점

| 계획 | 결과 | 이유 |
|---|---|---|
| 넘치면 5줄로 자르고 `외 N건`(D13) | 같은 종류의 장을 늘려 전부 싣는다(D15) | 카드뉴스의 목적은 정보 전달이다(사용자 지적) |
| 월 비용 영향(대표 4줄) + 이어서(6줄) | 차트 장 1장 + 목록 장(6줄마다) | 예외 규칙을 없애 장수 계산을 단순하게 한다 |
| `가정과 산출 근거` 장 | 두지 않는다 | 정보 전달 우선(D16) |
