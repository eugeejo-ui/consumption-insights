## 목표

Phase 1에서 정한 방향이 **실제로 구워지는지**, 한글이 로컬과 CI에서 제대로 그려지는지 확인한다. 실제 데이터를 넣어 구워 보며 드러난 조판 문제(서울 리전 누락, 한 음절 줄)를 규칙으로 고정한다.

## 이 단계의 결과

- **굽기 방식 확정:** 설치된 브라우저를 명령줄로 호출한다(D8). 새 패키지가 필요 없다.
- **글꼴 위험 확인:** CI 한글 글꼴 0개 [확인]. 이 위험이 이후 Phase 4의 출발점이다.
- **글자 수 상한 고정:** 표지 104px 10자×2줄, 본문 제목 76px 14자×2줄 등(스크립트 4절).
- **차트 장 규격 확정:** 범례, 막대 폭 30px·간격 12px, 두 리전 공통 최댓값 기준 높이, 금액 두 줄과 색 점, 각주 두 줄.
- **조판 규칙:** 단어 단위 줄바꿈, 여러 문장 각주는 문장마다 한 줄.
