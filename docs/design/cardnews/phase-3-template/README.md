## 목표

Phase 1·2의 방향과 규격을 **실제 카드 템플릿으로 구현**한다. 구현 전에 원본 템플릿과 다시 대조해 근사값을 바로잡고, 눈으로만 보던 검수 기준을 **브라우저 실측 검사**로 바꾼다.

## 이 단계의 결과

- **틀 규격 확정:** 좌우·상단 48px, 알약 높이 56px·아래 48px, 본문 블록 세로 가운데 정렬, 최소 여백 24px.
- **굵기 두 가지(400·700):** 로컬과 CI에서 굵기 때문에 글자 폭이 달라지지 않게 한다.
- **장 종류 다섯 가지:** `cover`, `bullets`, `chart`, `banners`, `closing`.
- **품질 검사가 코드로 들어갔다:** 숫자(보이는 글자 기준), 겹침, 넘침, 줄 수, 한 음절 줄, PNG 크기, PDF 쪽수.

## 다음 단계로 넘긴 것

- CI에서 매일 수집이 카드를 굽게 되면 한글 글꼴이 없어 두부 글자 카드가 생길 수 있다. 레이아웃 검사는 두부 글자를 잡지 못한다(→ 4-1).
- 글꼴 목록 끝의 `Noto Sans CJK KR`이 CI에서 라틴 글자까지 그리는지 확인하지 못했다 [미확인] (→ 4-1).
- 소개 카드의 새 장 종류(`chips`, `flow`)에도 측정 속성(`data-role`, `data-lines`)을 붙인다(→ 5-1).
