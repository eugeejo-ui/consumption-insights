## 세부 계획

**계기:** 사용자가 카드뉴스를 대시보드 안내로 끝맺는 장을 두고 싶다는 의사를 밝혔다(2026-09-14, 사용자 제시 사례). 스크립트와 장 구성에는 없었다.

**영향:** 장 구성, 최소 장수, 마지막 장 표시(`끝`), 카드 데이터 테스트의 장 순서가 모두 달라진다.

| 안 | 내용 | 판단 |
|---|---|---|
| **A (권고, 채택)** | 카드 데이터 구현 전에 마무리 장 문안까지 확정하고 포함한다 | 테스트를 한 번만 쓴다 |
| B | 현재 구성으로 진행하고 나중에 별도 개정 | 테스트를 다시 고쳐야 한다 |

**D16과의 관계:** D16은 `가정과 산출 근거`라는 **고지 장**을 뺀 결정이다. 마무리 안내 장은 고지 장이 아니라 안내 장이므로 D16을 유지한 채 더한다.

### 장수 규칙 변화

| 종류 | 이전 | 이후 |
|---|---|---|
| 정기 | 최소 4장 | **최소 5장** (표지 · 단가 · 차트 · 월 사용료 목록 · 마무리) |
| 소개 | 4장 | **5장** |
| 순위가 바뀐 날 / 벤더 개편 | 5장 / 8장 | 6장 / 9장 |

### 함께 정리한 것

- **생략 문구가 아니다**(규칙 18). 변동 항목은 앞 장에 전부 싣고, 이 장은 카드에 싣지 않는 비교 전체와 산출 근거의 **위치**를 알린다.
- 소개 4장 각주에서 `산출 근거는 대시보드에 있습니다`를 뺐다. 바로 다음 장이 같은 내용을 알린다(차트 장 각주 D19와 같은 처리).
- 문안 점검(`/humanize-korean`)에서 리드의 `월 사용료와 서울 프리미엄, …`을 `월 사용료, 서울 프리미엄, …`으로 고쳤다. `와`와 쉼표가 섞여 두 묶음으로 읽혔다.
