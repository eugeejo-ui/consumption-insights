## 목표

첫 LinkedIn 게시물에 쓸 소개 카드 5장을 만든다. 정기 카드에 없던 **새 장 종류 두 가지(과금 단위 칩, 파이프라인 흐름)** 를 같은 틀로 설계하고, 로컬에서 굽는 카드가 CI 카드와 같은 글자 모양이 되게 한다.

| 장 | 틀 | 내용 |
|---|---|---|
| 1 표지 | `cover` | 데이터 플랫폼 네 곳의 **월 사용료 추적** |
| 2 문제 제기 | `chips` (신규) | 가격표만으로는 **비교되지 않습니다** + 과금 단위 칩 4개 |
| 3 구조 | `flow` (신규) | 사람의 **승인**을 거칩니다 + 4단계 흐름 |
| 4 현재 결과 | `bullets` | 현재 **결과** + T1(리전별)·T2 |
| 5 마무리 안내 | `closing` | 3-1과 같다 |

## 이 단계의 결과

- **장 종류 일곱 가지:** 기존 다섯 가지에 `chips`, `flow`.
- **글꼴 정합:** 로컬(Noto Sans KR)과 CI(Noto Sans CJK KR)가 같은 Noto 계열로 굽는다.
- **실물 [확인]:** 소개 카드 5장 레이아웃 검사 통과(가장 좁은 여백 245px, 가장 오른쪽 글자 끝 1020/1032px). 게시 주소의 PDF와 PNG가 저장소 파일과 같다.
