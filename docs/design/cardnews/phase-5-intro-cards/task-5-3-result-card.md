## 세부 계획

**계기:** 소개 4장 `현재 결과`의 확정 문안(2026-09-12)을 코드와 대조하니 데이터에 따라 틀린 문장이 될 수 있었다.

```
T1 {판정} · 시나리오가 달라도 월 사용료 1위는 동일합니다.
T2 {판정} · 서울 프리미엄 격차 {격차}%p.
시나리오별 월 사용료 1위는 {플랫폼}입니다.
```

| # | 문제 | 근거 |
|---|---|---|
| a | T1은 **리전마다 판정**하는데 판정 자리가 하나다 | 대시보드도 T1을 미국 리전·서울 리전으로 나눠 표시한다 |
| b | `1위는 동일합니다`는 **기각일 때만 참**이다 | T1 가설은 "월 사용료 1위는 워크로드마다 다르다" |
| c | `1위는 {플랫폼}입니다`는 1위가 모든 시나리오·두 리전에서 하나일 때만 쓸 수 있다 | 리전마다 1위가 다를 수 있다 |
| d | T2 줄이 명사구로 끝나 무엇을 채택했는지 밝히지 않는다 | 규칙 17 |

**계획:** 항목 구조를 리전별로 바꾸는 보완안을 만들고, `/humanize-korean` 점검을 거쳐 승인받은 뒤 구현한다. 항목 수와 글자 수 상한은 유지한다.

## 결과

### 장 구성

| 요소 | 내용 |
|---|---|
| 제목 | 현재 **결과** |
| 리드(신규) | `월 사용료가 가장 낮은 플랫폼이 1위입니다.` (`1위`의 뜻을 밝힌다) |
| 항목 1·2 | 굵은 첫 줄 `T1 {판정} · {리전}` (미국 리전 → 서울 리전) |
| | 설명 [기각] `시나리오가 달라도 1위는 {플랫폼}로 같습니다.` / [채택] `시나리오에 따라 1위가 달라집니다.` |
| 항목 3 | 굵은 첫 줄 `T2 {판정}` |
| | 설명 [채택] `서울 프리미엄은 서비스마다 최대 {격차}%p 다릅니다.` / [기각] `서울 프리미엄의 서비스 간 차이가 {격차}%p로 작습니다.` |
| 각주 | `{작성일} 승인 스냅샷 기준입니다.` / `약정 할인을 제외한 모델 추정치입니다.` |

- 항목은 3개로 기존과 같다. 레이아웃은 기존 `bullets` 장(굵은 첫 줄 + 회색 둘째 줄)을 그대로 쓴다.
- 조사 `로`는 고정이다. 네 플랫폼 이름이 모두 모음으로 끝난다.
