## 목표

LinkedIn 문서 게시에 쓰는 **PDF가 사용자가 승인한 PNG와 같은 모습**이 되게 한다. 게시 형식(PDF 문서 / 사진)에 따라 카드 모습이 달라지지 않게 한다.

## 세부 과제

| 과제 | 계획 | 결과 |
|---|---|---|
| [6-1 PDF를 PNG로 조립](task-6-1-pdf-from-png.md) | 강조 문구 테두리선의 원인을 찾고, PDF를 구운 PNG로 조립한다 | 원인은 그라데이션 강조의 소프트 마스크다 [확인]. PDF 마스크 11 → 0, 가장자리 편차 0, PNG 변경 없음 |

## 이 단계의 결과

- **게시물 모습의 정본은 PNG다.** PDF는 PNG를 쪽마다 싣기만 한다.
- **원칙 5(강조는 그라데이션 한 곳)를 유지했다.** 디자인을 바꾸지 않고 산출 방식만 바꿨다.
- 굽기 코드가 이미지 수와 소프트 마스크를 검사하므로 같은 결함이 CI 정기 카드에서 다시 생기면 굽기가 멈춘다.
