## 목표

카드뉴스는 **사전 정보가 없는 LinkedIn 독자**가 읽는다. 프로젝트 내부 개념(가설 기호 T1·T2, 시나리오 이름, 승인 절차 용어)을 카드에서 걷어내고, 화면에 남는 정보만으로 뜻이 통하게 한다.

## 이 단계의 결과

- **카드에서 가설과 시나리오가 사라졌다.** 카드 글자에 `T1`·`T2`·`채택`·`기각`·`시나리오`가 없다는 것을 테스트가 막는다.
- **새 조판 요소가 생겼다.** 비교 기준 줄(`.basis`, 22px, 흐린 회색)은 각주보다 작고 한 줄이다.
- **읽는 사람이 오해할 표현을 걷어냈다.** 1장 리드와 게시문 첫 줄의 `매일`은 게시 주기로 읽혔다. 마무리 안내 장의 `시나리오별`·`서울 프리미엄`은 대시보드 용어였다.
