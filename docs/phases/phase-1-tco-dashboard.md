| BigQuery 컴퓨트 | 가격 페이지 | 수동 | Enterprise 슬롯-시간(종량제) $0.06 / $0.0765, 온디맨드 TiB $6.25 / $7.50 | 사용자 확인 2026-09-11 |
| BigQuery 스토리지 | 가격 페이지 | 수동 | Active physical GiB-월 $0.04 / $0.052 | 사용자 확인 2026-09-11 (월 기준 표시값도 일치) |

**BigQuery 가격표 참고 사항**
- **스토리지:** 가격 페이지는 GiB-시간과 GiB-월 두 가지로 표시한다.
  - **물리(사용 중):** US(us) $0.000054795/시간 = $0.04/월, 서울 $0.000071233/시간 = $0.052/월
  - **논리(이전 사용, 기록용):** US(us) $0.000027397 → $0.02, 서울 $0.000031507 → $0.023
- **리전 이름:** 페이지의 리전 이름은 "US (us)"다. 매월 무료 구간(스토리지 10GiB, 온디맨드 쿼리 1TiB)은 TCO 모델에서 제외한다.
- **컴퓨트 가격이 있는 곳:** 온디맨드는 **주문형 컴퓨팅 가격 책정**의 쿼리 행("1 tebibyte and above")에, 슬롯은 **용량 컴퓨팅 가격 책정**의 **기본값**(종량제) 열에 있다.
- **약정 가격 (모델에서는 쓰지 않음):** 미국 BigQuery CUD 1년 $0.054 / 3년 $0.048, 리소스 CUD 1년 $0.048 / 3년 $0.036. 서울 BigQuery CUD $0.06885 / $0.0612, 리소스 CUD $0.0612 / $0.0459.

| "8 RPU = small" 가정이 Redshift에 유리할 수 있음 | 미국에서는 T1이 "민감"으로 나와 영향이 드러났다. Phase 4에서 보정한다 |
