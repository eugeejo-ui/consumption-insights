## 이 Phase에서 답하려는 질문
- **T1:** 워크로드마다 월 비용 1위 플랫폼이 다른가? 가정을 ±50% 흔들어도 1위가 그대로인가? 미국과 서울을 모두 판정한다.
- **T2:** 서울 리전 추가 비용(서울 프리미엄)이 서비스마다 다른가? 기준은 최대값과 최소값의 차이가 10%p 이상인가이다.

**BigQuery 가격표 참고 사항**
- **스토리지 단위 변환:** 가격 페이지는 스토리지를 **GiB-시간** 단위로 표시한다. 가격표에는 730시간/월을 곱한 GiB-월 값을 적는다.
  - **물리(현재 사용):** US(us) $0.000054795 → $0.04, 서울 $0.000071233 → $0.052. 저장해 둔 페이지 데이터에서 뽑은 후보이며, 확인 대기다.
  - **논리(이전 사용, 기록용):** US(us) $0.000027397 → $0.02, 서울 $0.000031507 → $0.023. 사용자 확인 2026-09-11.
- **리전 이름:** 페이지의 리전 이름은 "US (us)"다. 매월 무료 구간(스토리지 10GiB, 온디맨드 쿼리 1TiB)은 TCO 모델에서 제외한다.
- **컴퓨트 가격이 있는 곳 (사용자 확인 완료)**

  | 가격표 행 | 페이지 섹션 | 볼 곳 | 미국 / 서울 |
  |---|---|---|---|
  | 온디맨드 | **주문형 컴퓨팅 가격 책정** | 쿼리(주문형) 행의 "1 tebibyte and above" | $6.25 / $7.50 per TiB |
  | 슬롯 | **용량 컴퓨팅 가격 책정** | **기본값**(종량제) 열 | $0.06 / $0.0765 per slot-hour |

- **용량 컴퓨팅의 약정 가격 (사용자가 붙여 준 표, 모델에서는 쓰지 않음)**
  - 미국: BigQuery CUD 1년 $0.054 / 3년 $0.048, 리소스 CUD 1년 $0.048 / 3년 $0.036
  - 서울: BigQuery CUD 1년 $0.06885 / 3년 $0.0612, 리소스 CUD 1년 $0.0612 / 3년 $0.0459

## T1·T2 판정 결과 (Task 6 미리보기)
- 기준: `config/thresholds.yaml` (±50%, 10%p)
- 가격: 실제 가격표 값 + BigQuery 물리 스토리지 후보값
- 정식 판정은 Task 8에서 실제 스냅샷으로 한다.

| 판정 | 미국 | 서울 |
|---|---|---|
| **T1** 1위가 워크로드마다 다른가 | **기각**: W1·W2·W3 모두 Redshift. 세 시나리오 모두 **민감** | **기각**: W1·W2·W3 모두 Redshift. 세 시나리오 모두 **견고** |
| **T2** 서울 프리미엄이 서비스마다 다른가 | **지지**: 최대-최소 차이 39.5%p | (리전 비교 지표라 하나의 판정) |

**왜 미국은 민감하고 서울은 견고한가**
- **미국:** Snowflake의 용량 가정을 ×0.5로 하면 세 시나리오 모두에서 Redshift보다 싸진다(W1 $890 < $900, W2 $590 < $600, W3 $350 < $360).
- **서울:** Redshift 컴퓨트 프리미엄(+16.8%)이 Snowflake(+35.0%)보다 훨씬 낮다. 그래서 Snowflake를 ×0.5로 해도 Redshift를 넘지 못한다(W1 $1,141 > $1,032).
- **의미:** "어느 플랫폼이 싼가"는 가정뿐 아니라 **리전**에 따라서도 확실성이 달라진다.
- **반영:** 이 결과 때문에 대시보드는 T1을 미국·서울 두 리전 모두 표시한다(2026-09-11 사용자 결정, Task 7).
