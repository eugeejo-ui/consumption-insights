## 이 Phase에서 답하려는 질문
- **T1:** 워크로드마다 월 비용 1위 플랫폼이 다른가? 가정을 ±50% 흔들어도 1위가 그대로인가?

**BigQuery 가격표 참고 사항**
- **스토리지 단위 변환:** 가격 페이지는 스토리지를 **GiB-시간** 단위로 표시한다. 가격표에는 730시간/월을 곱한 GiB-월 값을 적는다.
  - **물리(현재 사용):** US(us) $0.000054795 → $0.04, 서울 $0.000071233 → $0.052. 저장해 둔 페이지 데이터에서 뽑은 후보이며, 확인 대기다.
  - **논리(이전 사용, 기록용):** US(us) $0.000027397 → $0.02, 서울 $0.000031507 → $0.023. 사용자 확인 2026-09-11.
- **리전 이름:** 페이지의 리전 이름은 "US (us)"다. 매월 무료 구간(스토리지 10GiB, 온디맨드 쿼리 1TiB)은 TCO 모델에서 제외한다.
- **컴퓨트 가격이 있는 곳 (사용자 확인 완료)**

  | 가격표 행 | 페이지 섹션 | 볼 곳 | 미국 / 서울 |
  |---|---|---|---|
  | 온디맨드 | **주문형 컴퓨팅 가격 책정** | 쿼리(주문형) 행의 "1 tebibyte and above" | $6.25 / $7.50 per TiB |
  | 슬롯 | **용량 컴퓨팅 가격 책정** | **기본값**(종량제) 열 | $0.06 / $0.0765 per slot-hour |

- **용량 컴퓨팅의 약정 가격 (사용자가 붙여 준 표, 모델에서는 쓰지 않음)**
  - 미국: BigQuery CUD 1년 $0.054 / 3년 $0.048, 리소스 CUD 1년 $0.048 / 3년 $0.036
  - 서울: BigQuery CUD 1년 $0.06885 / 3년 $0.0612, 리소스 CUD 1년 $0.0612 / 3년 $0.0459
  - 앞서 "1년 $0.048 / 3년 $0.036"으로 안내한 것은 부정확했다. 약정은 BigQuery CUD와 리소스 CUD 두 종류다.

## 가정 검토 결과 (2026-09-11)
사용자 요청에 따라 Claude가 검토했다. 기준은 "바꿀 값이 있으면 중단하고 반영한다"이다.

| 가정 | 판단 | 조치 |
|---|---|---|
| **스토리지 10TB의 기준** | **변경 필요.** Snowflake·Redshift·ADLS는 압축된 저장량으로 과금하는데, BigQuery의 active *logical* storage는 압축 전 저장량으로 과금한다. 같은 데이터에서 BigQuery 비용이 압축률만큼 과소평가된다 | 기준을 "압축(물리) 후 10TB"로 통일하고, BigQuery는 **active physical storage** 단가를 쓴다. 공시 가격을 쓰는 방식이라 압축률을 따로 가정하지 않아도 된다 |
| W3 스캔량 20TiB | 유지. 기준이 모호했다 | **논리(압축 전) 바이트** 기준으로 명시한다. BigQuery 온디맨드 과금 기준과 같다 |
| small 1단위 동등성 | 유지. 벤더의 크기 이름 기준이고 성능 동등성은 검증할 수 없다 | Task 6의 ±50% 민감도와 Phase 4 실측 보정으로 다룬다. 한계는 `workloads.yaml` 주석과 아래 위험 표에 적는다 |
| W1 220시간, W2 60시간 | 유지. 일반적인 BI·배치 사용 패턴으로 무리가 없다 | — |
| 제외 항목(송출, 무료 등급, 최소 과금, 약정) | 유지. 가정 공개 섹션에 명시한다 | — |

## 핵심 가정 (결과를 좌우한다. `data/manual/workloads.yaml`)
- **small 1단위:** Snowflake 시간당 2크레딧 / Databricks 시간당 12 DBU / Redshift 8 RPU / BigQuery 100슬롯
- **시나리오:**
  - W1: small×1로 월 220시간
  - W2: small×2로 월 60시간
  - W3: 월 20TiB(논리 바이트) 스캔. BigQuery는 온디맨드로 과금하고, 나머지는 small×4가 시간당 2TiB를 스캔한다고 보고 10시간으로 계산한다
- **스토리지:** 압축(물리) 기준 10TB
- **제외 항목:** 네트워크 송출, 무료 등급, 최소 과금 단위, 약정 할인
- **미리보기** (물리 스토리지 후보값 반영): W1·W2·W3 모두 Redshift가 가장 싸다(미국·서울 모두). 이전의 논리 스토리지 기준에서는 W3의 1위가 BigQuery였다.
