## 새 대화에 넘길 것 (인수인계)

**지금까지 만들어진 것 (Phase 2 완료, 테스트 57개)**
- 대시보드: https://eugeejo-ui.github.io/consumption-insights/ · 저장소: https://github.com/eugeejo-ui/consumption-insights
- 매일 09:17(KST) 수집 → 단가가 바뀌면 검토 PR → 사람이 머지 → Pages 게시 + 시트 적재
- 글 초안은 이미 자동 생성된다: `publish/render_post.py` + `templates/post_price_change.md.j2` → `data/raw/<날짜>/post.md`
- 변동 내용은 `data/raw/<날짜>/events.json`에 있다(단가 변화, 월 비용 변화, 순위 변화, E1 여부)
- 화면 디자인 토큰은 `templates/site/index.html.j2`의 `:root` CSS 변수에 있다. 카드뉴스도 같은 색·글꼴을 쓰면 일관성이 생긴다

**지켜야 할 제약**
- LinkedIn 자동 게시는 약관 위반이다(아래 제약 절). **이미지와 문구 생성까지만 자동화하고, 게시 버튼은 사람이 누른다.**
- 숫자는 `events.json`에 있는 값만 쓴다(글 초안과 같은 검사 규칙).
- 화면 문구는 격식 있는 문어체다(CLAUDE.md 규칙 15). 카드뉴스 문구도 같은 기준을 따른다.
- 한 번에 Task 하나만 하고 보고한다(규칙 10). 계획 없이 실행하지 않는다(규칙 1).

**카드뉴스 만드는 방법 후보 (새 대화에서 비교해 결정)**
| 방법 | 장점 | 단점 |
|---|---|---|
| HTML 템플릿 + 헤드리스 크로미움 스크린샷 | 대시보드와 같은 CSS를 재사용한다. 레이아웃이 자유롭다 | Actions에 브라우저와 한글 폰트를 설치해야 한다 |
| SVG 템플릿 → PNG 변환 | 의존성이 가볍다 | 복잡한 레이아웃이 번거롭다 |
| Pillow로 직접 그리기 | 의존성이 가장 단순하다 | 디자인 손질이 번거롭다 |

**정할 것**: 카드 규격(예: 1080×1350 4~5장), 장 구성(표지 → 변동 요약 → 순위 → 가정·출처), 파일이 어디에 남는지(검토 PR 첨부 또는 저장소 `site/cards/`), 게시 방식(A'~C 중).

**새 대화 첫 마디로 쓸 문장**
> consumption-insights 저장소에서 Phase 3(LinkedIn 카드뉴스)을 진행한다. CLAUDE.md와 docs/phases/phase-3-linkedin.md를 먼저 읽고, 카드뉴스 자동 생성 + 게시 방식에 대한 진행계획과 코드 계획을 쓴 뒤 승인을 받아라. 계획 없이 구현하지 마라.
