# 검토 PR 본문 확정 문안 (스크립트)

> **상태: 1~4절 확정** (2026-09-15 사용자 승인, Task 6 Step 0). **5~7절 승인 대기** (Task 7 Step 0). 규칙 16에 따라 코드보다 먼저 작성하고 `/humanize-korean` 점검을 거친다. **이 문서가 문안의 정본이다.** 코드의 문구가 이 문서와 다르면 이 문서를 따른다.
> **어조:** executive 보고체. 결론을 앞에 두고 근거를 뒤에 둔다. 구어체를 쓰지 않는다.
> **범위:** 검토 PR 본문에 **새로 붙는 절**만 다룬다. 앞에 오는 검토 보고서(`review.md`)와 글 초안(`post.md`)의 문안은 기존 템플릿을 따르며, 용어 교체(D17)는 다른 대화에서 진행한다.
> **읽는 사람:** 검토 PR을 머지할지 판단하는 사용자. 공개 게시물이 아니다.

## 1. 장 이름

이미지 대체 텍스트 `{순번}장 {장 이름}`에 쓴다. 카드 스크립트(`docs/scripts/cards-script.md`)의 장 제목과 같다.

| 파일 이름 | 장 이름 |
|---|---|
| `cover` | 표지 |
| `price` | 단가 변동 내역 |
| `chart` | 플랫폼별 월 사용료 |
| `cost` | 월 사용료 변동 내역 |
| `rank` | 순위 변동 |
| `closing` | 마무리 안내 |

## 2. 카드뉴스 미리보기 절 (카드가 구워진 날)

```
## 카드뉴스 미리보기 · {장수}장

원본 PDF: [cards.pdf]({PDF 주소})
머지 후 게시 주소: {게시 주소}

[장수가 10장을 넘는 경우] 카드가 {장수}장으로 10장을 넘습니다. 게시 분량은 검토자가 판단합니다.

![{순번}장 {장 이름}]({이미지 주소})      ← 장마다 한 줄
```

- 경고 줄은 장수가 10장을 넘을 때만 출력한다(규칙 18). 장수를 줄이거나 항목을 생략하지 않는다.

## 3. 카드뉴스·게시문 생성 실패 절 (`card-errors.txt`가 있는 날)

````
## 카드뉴스·게시문 생성 실패

카드 또는 게시문 생성에 실패했습니다. 검토 자료는 정상입니다.

```text
{실패 사유}
```
````

- 사유는 요약하지 않고 원문 그대로 싣는다. 개발자용 진단 기록이므로 문안 점검 대상이 아니다.
- 카드가 구워지지 않았으면 2절은 출력하지 않는다. 게시문만 실패하고 카드는 구워졌으면 2절과 3절을 모두 출력한다.

## 5. 문구 보류 알림 (`copy-hold.txt`가 있는 날, 본문 맨 위)

```
> [!WARNING]
> 문구 재작성이 진행 중입니다. 지금 머지하면 승인과 게시가 진행되지 않습니다.
> [재작성 요청이 열린 경우] 재작성 요청: {요청 주소}
```

- 검토 보고서보다 앞에 둔다. 머지 버튼을 누르기 전에 보여야 한다.
- `revise-copy` 라벨을 붙이거나 뗄 때 워크플로가 본문을 다시 만든다. 라벨을 떼면 이 알림이 사라진다.
- 4회차부터는 재작성 요청을 열지 않으므로 요청 주소 줄이 없다.

## 6. 문구 반려 절 (카드나 게시문이 있는 날, 본문 맨 끝)

```

라벨이 붙은 동안에는 머지해도 승인과 게시가 진행되지 않습니다.
숫자와 항목은 데이터에서 오므로 반려 대상이 아닙니다.
```

- 줄마다 문단을 나눠 출력한다.

## 7. 재작성 상한 코멘트 (4회차 `revise-copy` 라벨, PR 코멘트)
