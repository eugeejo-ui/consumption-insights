## 게시 전 확인 (Claude, 2026-09-15) [확인]

| 항목 | 결과 |
|---|---|
| 보안 점검 후속 설정 | 워크플로 기본 토큰 권한 `read`, 액션 커밋 SHA 고정 요구 켜짐, main 규칙 `main-protect`(기본 브랜치, 삭제·강제 push 차단, 우회 주체 없음) 활성. Wikis·Projects 꺼짐, 머지 후 브랜치 자동 삭제 켜짐, 자동 머지 꺼짐 |
| 확인하지 못한 설정 | **Dependabot alerts는 API가 여전히 꺼짐으로 응답한다**(게시와 무관, 사용자 재확인). 이메일 비공개·커밋 코멘트·push 한도는 현재 토큰 권한으로 읽을 수 없다(사용자 화면 확인) |
| 소개 카드 최신성 | 최신 승인 스냅샷이 2026-09-11이고 카드도 이 스냅샷으로 구웠다. 카드 코드(`templates/cards`, `card_data.py`, `render_cards.py`)는 `cb2db9f` 이후 바뀌지 않았다. 다시 구울 필요가 없다 |
| 게시 주소 | `cards.pdf`, PNG 5장, `linkedin.md` 모두 HTTP 200. 게시된 PDF가 저장소 파일과 바이트 단위로 같다 |
| 게시문 | 숫자가 없는 고정 문안(스크립트 2절), 3,000자 이내, 해시태그 4개. 게시문의 `월 비용`과 카드의 `월 사용료`가 다른 것은 D17의 의도된 불일치다 |

## 사용자 게시 절차

| 단계 | 할 일 | 주소·참고 |
|---|---|---|
| 1 | 파일을 받는다. 넘겨 보는 문서로 올리려면 PDF, 사진으로 올리려면 PNG 5장 | `https://eugeejo-ui.github.io/consumption-insights/cards/intro/cards.pdf`, `…/01-cover.png` ~ `…/05-closing.png` |
| 2 | 게시문 전체를 복사한다 | `https://eugeejo-ui.github.io/consumption-insights/cards/intro/linkedin.md` |
| 3 | LinkedIn에서 새 게시물을 열고 문서(PDF) 또는 사진(PNG 5장, 01 → 05 순서)을 추가한다 | PDF 문서 게시는 문서 제목을 요구한다 [지식]. 새 문안을 만들지 않도록 확정된 표지 제목 `데이터 플랫폼 네 곳의 월 사용료 추적`을 쓴다(규칙 16) |
| 4 | 게시문을 붙여 넣고 미리보기에서 줄바꿈, 대시보드 주소, 해시태그를 확인한 뒤 게시한다 | — |
| 5 (선택) | 폰 브라우저에서 PNG를 열어 저장되는지 확인한다(3-9에서 넘긴 항목) | — |

## 게시 후 기록 (Claude, 사용자가 알려 준 뒤)

- 게시 날짜, 올린 형식(PDF 문서 / 사진), 미리보기에서 고친 점이 있었는지를 이 파일과 `CLAUDE.md` 진행 로그에 적는다.
- **게시물 주소는 사용자가 원할 때만 적는다.** 주소에 개인 프로필 정보가 들어갈 수 있다(규칙 11).
- `CLAUDE.md` 3-10을 완료로 표시한다. Phase 3 게이트(첫 게시 확인)를 통과하면 Phase 4 상세 계획은 사용자 지시 뒤에 쓴다.
